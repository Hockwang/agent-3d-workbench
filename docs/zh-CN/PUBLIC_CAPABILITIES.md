# 对外能力承诺

[English](../PUBLIC_CAPABILITIES.md)

通用 Agent 读取共享 3D 状态、执行本地操作、查看真实证据、继续修改并交付可编辑资产。
这条运行链路不需要专用 3D 生成模型、3D 服务账号或 API key。Agent 由宿主提供；
Python/Node、Blender、切片软件按具体任务安装。安装阶段可能下载依赖；运行无需生成服务不等于离线安装。

## 承诺提供的能力

| 能力 | 契约与验收 |
|---|---|
| 共享编辑 | 导入支持的资产，读取对象/单位/选区/版本，定向编辑、撤销和保存；可重开目录工程。整体归档替换需独立模型分支，共享工程会拒绝整体替换；过期或不兼容修改拒绝执行。 |
| 本地建模 | 执行 Agent 编写的 Python/CadQuery/Blender，按任务交付 STEP/STL/GLB/Blender 文件；实测尺寸与实体，不保证任意艺术造型。 |
| 网格处理 | 变换、布尔、平切、连通块、明确面标签拆分、小洞修复、减面；面标签由 Agent/用户给出，不承诺自动语义归属。 |
| 材质与表面 | 材质槽、贴图替换、UV、烘焙、明确区域的光顺/拉长；改变几何后需复核接缝和外观。 |
| 功能加工 | 明确的内腔/盖子、头壳、局部尺寸计划，以及下列四种制造任务；输入与保护范围必须明确。 |
| 骨架与动作 | 明确骨架绑定、权重修复、明确骨名映射重定向、关节/关键帧编辑与动画导出；自然度、自动解剖和姿态保持另验。 |
| 场景和二维加工 | 本地摆放/渲染、离线交互页、灰度浮雕、SVG 分层；用户资产或本地程序几何作为输入。 |
| 观察 | 真实渲染、统一相机/尺度、几何指标和绑定版本的评审；执行成功不代替质量结论。 |
| 机构检查 | 指定离散姿态的实体相交、有限组合关节采样、离散拔出检查；保留覆盖范围和未检查条件。 |
| 打印准备 | 朝向、排盘、几何/工程导出、本地切片估算；实物配合、强度、磨损和实际发打印不属于数字验收。 |

## 补齐的四个制造任务

统一调用 `studio_task(action="start", template=..., inputs=[...], params={...})`，
用 `studio_tasks(id=...)` 等待并取产物。输入为本地绝对路径。
必须读取 `report.json` 和实际文件：`completed` 只代表进程完成，报告的 `status` 才是几何结论。
源文件不修改；结果通过现有带 revision 检查的编辑器导入，或以 `studio_load` 重载新 STL 后再排盘。
后台任务不会自动替换当前模型，也不会自动完成整条配方。

### `connect-parts`：定位销与盲孔

输入恰好两个在平面上接合的闭合、连通静态对象。`parts` 按轴负侧/正侧填写场景节点名。
`connectors` 为 1–16 个计划：`center_mm`、`axis`、可选 `x_hint`、`profile`
（`round`/`keyed`）、`radius_mm`（默认 2）、`depth_mm`（6）、`clearance_mm`（0.2）、
`min_wall_mm`（1.6）。多根销必须同向平行。

交付两件盲孔加工件、独立圆销/D 形销、STL/GLB 和报告。完整保守孔壁/孔底包络必须位于主体内；
薄壁、不连通和采样拔出碰撞会拒绝。孔壁下界只适用于这些孔，不是全模型最薄壁厚。
定位销用于间隙/胶接，不承诺摩擦保持力。

### `color-inlays`：调色板分色嵌件

输入单个闭合静态对象，含不透明顶点/面颜色或 UV 贴图。给出 `palette_rgb`
（2–8 个 RGB 字节三元组，首色留作主体）、`pull_direction`、`depth_mm`（1.2）、
`clearance_mm`（0.15）、`min_patch_area_mm2`（4）、`max_color_distance`
（归一化 RGB 距离 0.25）、`min_pull_cosine`（0.25）。最多处理 5000 个选中三角面。

贴图采用 UV 顶点采样后逐面平均；大三角面跨越细纹时先细分，不声称恢复全部纹理细节。
UV/颜色接缝的重复顶点不切断几何连通性。色块须面向同一个拔出方向；过小区域明确列为涂装提示。
沿指定方向向内加厚并与源实体求交，凹槽使用轴对齐 L-infinity 间隙包络。
交付闭合、调色板纯色嵌件和主体，检查 33 档拔出位置；不承诺源贴图保留或整体最薄壁厚。
绕背色区、透明、颜色超差、采样拔出受阻明确拒绝。
额外加销为可选，须另有符合 `connect-parts` 条件的平面接缝。

### `install-joint`：安装关节模块

输入两个闭合主体。提供 `parts`（固定/活动节点名）、`family`
（`pin_hinge`/`slew`/`slider`/`ball_socket`）、`center_mm`、`axis`、可选 `x_hint`、
世界坐标的两个 `anchors_mm`，以及世界轴对齐 `machining_box_mm: [[xmin,ymin,zmin],[xmax,ymax,zmax]]`。
`mount_radius_mm` 控制连接杆半径。连接杆必须真正与保留主体相交；加工区外不得增料/去料。

交付闭合连通件、静止交叠结果、源哈希、改动体积、独立五金清单，以及绑定**新 STL** 的 `assembly.urdf`。
输入几何用毫米；URDF 行程用弧度/米。`joint_limits` 每关节一对上下限（球窝三对），必须包含零位，
只是待检查范围。销铰用 M2 螺钉/螺母；回转有胶接端帽；滑轨无端部限位；球窝有可拆上盖和两组 M2 通孔螺栓。
球窝成形不代表摩擦保持姿势已验证。新 URDF 交给 `motion-check`，装配顺序、外观和实物试片分别验收。
本模板不提供伸缩连杆和任意关节族。

球窝可设置 `ball_radius_mm`（5）、`socket_wall_mm`（2）、`stem_swing_rad`（0.55），
最后一项控制杆口的锥形让位角；它不是已验收行程，仍需检查安装主体后的组合姿态。

### `motion-check`：组合姿态检查

输入一个引用本地闭合网格的 URDF。`sampling="grid"` 对每个独立关节采样 `steps`
（默认 5）个值并取笛卡尔积；或使用 `sampling="explicit"` 和含全部独立关节名的 `configurations`。
上限 4096 个组合，超出时拒绝，不暗自降采样。`joint_ranges` 可指定范围；连续关节必须给范围。
固定连接组和 mimic 关节沿用现有 URDF 解析规则。

`motion-check.json`/`report.json` 返回每个姿态和碰撞对、`clear_configurations`、
`sampled_clear_values` 与依赖文件哈希。**各轴无碰撞值不能任意重新组合成安全行程**，
因为某个值可能只在另一关节特定取值时才安全。连续碰撞、防脱、力和磨损未验。
测出碰撞时报告 `status=fail`；进程成功不会把失败结论改成通过。

## 不纳入承诺的能力

任意照片高质量重建、自动语义拆装、保身份人像重建、任意动物自然运动、实物装配/强度保证和自动发打印。
托管适配器与 `image-to-print` 配方为可选扩展，不属于本地承诺。
鼠标/原生宿主集成和干净机器安装需按宿主实测，内核测试不替代它们。

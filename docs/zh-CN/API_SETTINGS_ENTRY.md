# API 配置入口

工作台顶部提供 **API 配置**，模型编辑、动作编辑、任务、观察及打印准备页面均可打开。任务表单保留同名按钮。两个入口共用一个连接窗口，保存连接后刷新任务页的服务选项。

服务说明使用协议或服务商名称，移除组织特定称呼。Seed3D 模板名称改为 **Chat Completions 兼容网关**。已有自定义连接名称属于用户数据，更新不会覆盖它们。

实现由 `studio/web/workspace.js` 管理共享窗口，`tasks.js` 复用窗口并刷新服务。没有服务管理能力的传输层隐藏入口。打包的 MCP App 随源代码一起重建。

后端消息目录由进程缓存。如果已有进程仍显示旧模板文案，重新连接插件或重启后端后生效。

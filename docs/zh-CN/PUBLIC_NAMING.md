# 插件公开命名约定

任务标题、成果卡片、模型卡片、动画菜单和公开指南使用“自动绑骨”“动作生成”“分件方案 A/B”等功能名称，不将底层研究实现名称作为默认功能标签。

`studio/web/display-label.js` 在显示时统一格式化旧任务元数据和导入动画标签。两种语言共用此处理，包括已有模型别名和刚重命名的卡片。Agent 技能也要求新任务和说明使用功能名称。

不改写任务 ID、原始证据、模型字节、骨骼或动画绑定、请求参数及下载文件名。依赖要求的许可证声明保留。配置具体 API 所必需的服务商名称仍可见。

回归测试覆盖两种语言、旧成果元数据、模型卡片标题、原始资产数据不变，以及无关用户名称保持原义。

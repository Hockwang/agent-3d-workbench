# 任务配方接入与验证 · 2026-09-21

将本项目已有 Claude 配方层适配到通用 3D 工作台，复用现成编辑工具，不新增另一套几何实现。
内置 17 条路线，10 条具备运行工具、7 条明确显示缺口；这不代表安装了其他产品全部算法。

## 可以使用的路线

| 工作区 | 路线 |
|---|---|
| 模型编辑 | 检查与基础修复、模型减面、连通块拆件、平面切成两件、调整模型材质 |
| 打印准备 | 整件手办直接打、功能件与结构件、多件套件分盘、浮雕与薄板、只估料和时间 |

7 条等待能力的路线：分色分件、切开加销、一张图到打印、机械件加铰链滑轨、人偶加可动关节、拆件胶装套件、先打配合试片。
缺口包含语义/颜色分割、定位销孔、装配路径和运动验证、关节、配合试片、生成服务与可打印性检查。
平面切割和连通块拆分已接通，但不等于语义分割。打印路线的试切依赖本机 Bambu Studio；本轮未执行实际打印。

## 文件与实现原因

| 文件 | 改动与原因 |
|---|---|
| `recipes/`、`studio/recipes.py` | 复用 12 条自有配方及严格数据加载器，新增 5 条现有编辑路线；统一能力可用性和中文缺口提示 |
| `studio/recipe_schema.py`、`studio/tools_schema.py` | 3 个配方工具进入统一工具表，MCP 共 17 个工具 |
| `studio/recipe_progress.py` | 编辑步骤绑定当前模型与选区，成功操作才推进；换选区、撤销及无关几何编辑使凭据失效 |
| `studio/server.py`、`studio/history.py` | 单飞写入、持久化配方状态、幂等启停；保留已有打印结果失效规则 |
| `studio/web/recipes.js`、`recipes.css`、`workspace.js`、`index.html` | 两个工作区共享配方栏，步骤按钮定位到实际操作控件，窄栏抽屉可滚动 |
| `studio/web/editor.js`、`flow.js`、`api.js`、`studio/app/api.js` | 编辑操作定位、历史中文标签、HTTP/MCP 同一契约 |
| `scripts/build_app.mjs`、`studio/app_resources.py`、`studio/app/dist/studio.html` | 配方样式进入自包含包，UI 资源改为 v6，保持卡片不加载 WebGL |
| `skills/print-prep/SKILL.md`、`README.md`、`SPEC_RECIPES.md` | 更新工具使用方式、能力边界及状态语义 |
| `tests/test_recipe_workbench.py`、`test_recipes.py`、`test_recipes_ui.mjs`、`test_mcp_server.py` | 实际编辑路线、撤销/选择/失败、工具契约、数据校验与 UI 工具适配回归 |

配方是 JSON/Markdown 数据，不执行脚本；不允许预置文件路径、对象 ID、工程版本或丢贴图许可。
编辑完成进度表示对应操作已执行，不能代替人工质量判断和工具返回的具体检查结果。
内容摘要改变后需要重新启用；打开目录时刷新缓存，状态轮询不重复读全部配方和几何。

来源是本项目自有 Claude 开发支线的 `recipes/`、加载器及界面代码；5 条编辑路线基于本仓已有操作契约编写。
未复制第三方闭源 skill、提示词或工作流实现；开源几何依赖仍以 `THIRD_PARTY.md` 为准。

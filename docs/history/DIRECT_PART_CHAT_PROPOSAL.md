# 零件聊天分支：直接创建方案（已确认并实施）

日期：2026-09-23。状态：用户已要求继续实施；实现与验收见 [DIRECT_PART_CHAT.md](../DIRECT_PART_CHAT.md)。以下保留实施前的方案和取舍。

## 目标

点击“创建聊天分支”后由程序创建真实 Codex 分支，绑定当前 3D 工程和指定零件，返回可打开的任务入口。父任务不接收生成分支的提示词，不运行模型回合；创建本身也不启动子任务修缮。保留同目录共享工程、逐零件版本和租约约束。

## 已核实的接入事实

- 现有入口 `studio/app/api.js:createPartChat` 调用 `sendMessage`；操作步骤来自 `studio/web/part-chat.js`。
- 当前安装的 `@modelcontextprotocol/ext-apps` 为 2.0.0。`callServerTool` 指向本 UI 所属 MCP server；其声明没有原生任务分支授权接口。
- 本机 `codex-cli 0.154.0` 提供 `app-server proxy`、daemon 管理和协议 schema 生成命令。
- 本轮 `codex app-server daemon version` 未能连接默认 control socket，原因是文件不存在。
- 本轮进程参数检查显示桌面 App Server 使用 `stdio://`。未连接、重启或更改这些进程。
- 官方 App Server 文档提供 `thread/fork`、`thread/read`、`thread/name/set` 和 Unix socket/stdio 传输：https://learn.chatgpt.com/docs/app-server 。这些协议能力不等于已验证桌面任务列表的兼容性。

## 建议路径

工作台按钮 → 本插件后端 → 受限本地 Codex adapter → 官方 `thread/fork` → 工程绑定 → 返回任务 ID 与状态。

优先连接用户启用、可用且经过身份检查的共享 App Server。当前默认端点不可用，因此第二候选是用户明确启用的官方 App Server 本地集成进程；必须先验证它创建的持久化分支能被当前桌面正常列出、打开、继续，才能用于产品。不得把 CLI session ID 或另一个服务的任务当成已成功接入桌面的证据。

这是一条待验证的后端集成路径，不通过读取/改写 Codex 私有数据库、伪造 rollout、注入桌面进程或操作其私有 IPC 实现。

## 最小原型的验收顺序

1. 使用安装版本生成协议 schema，确认 fork 参数、返回身份、目录和历史范围；只读核对父任务。
2. 在用户确认的验证任务上创建一个持久化分支，不调用 `turn/start`；父任务不得被中断或写入新消息。
3. 用桌面自身任务读取/导航能力确认子任务真实存在且可打开，保留父任务来源和正确工作目录。连接断开后仍可读取。
4. 通过插件后端的受限协调操作，将返回的子任务绑定到源工程/零件。实现前需明确协调者身份，不能通过伪装成另一个 `workspace_id` 绕过现有 own-session 约束。
5. 子任务打开工作台后读到同一个工程；首次用户修缮要求能正常执行，只能修改指定零件及派生件。
6. 任一步不成立则报告具体接入限制，不把“已提交请求”显示成“创建成功”。

## 授权和交互

- 设置项：“允许工作台直接创建零件聊天分支”，默认关闭，可撤销。它是本地集成授权，不声称改变 Codex 宿主权限。
- 启用前检查 adapter 和桌面兼容性；缺少能力时禁用按钮并给出明确原因。
- 用户授权限制到当前工程和目录、读取父任务必要信息、创建其分支、绑定指定零件和设置标题；前端不获得任意 RPC 或执行命令入口。
- 点击后展示“正在创建”；成功后展示“打开分支”。拒绝授权时禁用功能，设置中可重新开启。
- 不自动回退到发送提示词。

## 一致性要求

请求带操作 ID，并在后端持久化“创建中 / 已取得 child ID / 已绑定 / 失败”状态。重复点击或超时重试应复用同一操作；一旦取得 child ID，不得重新 fork。返回结果不确定时先核对，不能盲重试。

创建与工程绑定不是跨系统原子事务。绑定失败时保留 child ID，显示真实状态并允许重试绑定；未获单独授权不删除用户任务。绑定前后校验零件版本和共享目录。授权撤销不删除已创建任务，后续新请求应被后端拒绝。

## 实施范围与取舍

需要新增本地 adapter、创建操作状态存储、后端授权检查及工程协调绑定入口，再改 UI。属于跨系统接入，先确认该方案后实施。现有消息创建方式的问题已定位；本方案尚未更改运行时或创建验证任务。

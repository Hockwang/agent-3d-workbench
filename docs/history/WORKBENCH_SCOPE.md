## 1. 产品定位

做面向人和 AI 的 3D 工作台。用户带入已有模型，用选取、按钮和参数完成明确操作；AI 在同一份模型与选区上处理复杂步骤。打印准备是工作台中的一个模块。

依据：内部产品设想与路线文档（Confluence 版本 3）。原文是定位与路线文件，首发详细功能清单仍待冻结；本文补充功能地图及代码来源。

- Codex 右侧为主要工作区；对话负责指令、解释、摘要与打开入口。
- 不购买官方 API，也能完成已支持的本地手动编辑与导出。
- 人和 AI 共用模型、选区、参数、操作结果与恢复机制。
- MDE 已探索的模型编辑能力都进入能力盘点；成熟的自有工具逐项产品化，实验能力标明适用条件。
- 服务型生成与分割提供可选适配器；BYOK 和官方服务均可接入，不把某个模型厂商写死在编辑流程里。
- Codex 先行；WorkBuddy 与独立网站沿用原产品路线，分别验证宿主和部署。

## 2. 功能地图

这里的“已有基础”表示找到相关实现或实验记录，不等于当前插件提供该功能，也不代表已完成公开分发审查。

| 模块 | 用户应该能做什么 | 已有基础与接入判断 |
| --- | --- | --- |
| 模型与基础编辑 | 导入、模型树、多选、隐藏/隔离、命名、复制/删除、移动/旋转/缩放、量尺寸、保存与导出 | 当前插件已有导入、预览、选择、尺寸/朝向与制造导出；通用对象编辑、项目保存及可编辑 GLB 导出需要补齐。不能把打印朝向当作完整变换编辑器。 |
| 选区与拆件 | 按对象/连通块/面区选择，合并归组，平面切割，确认或修正 SEG 候选边界 | MDE 有切割几何工具、语义合件实验、P3 点选界面；先接明确输入的操作，再接模型候选。归组、合并 mesh 与实体布尔并集应区分。 |
| 几何检查与修复 | 看开边、非流形和组件问题，修正法向，补洞/封口，清理碎片，按明确参数减面或重网格 | 有局部修复、实体化、布尔操作和表面保真检查；通用修复器需重新封装。减面与重网格列为待核实/实现项，现有预览减面不计入交付能力。 |
| 装配与结构加工 | 零件对齐、布尔加工、销孔/连接件、间隙、装配顺序和路径检查 | 制造工具中有定位接口和装配检查；多处输入依赖已审核计划。需拆出独立操作，提供宿主面、加工区和保护区交互。挖空/加厚等局部方法不直接宣称适用于任意壳体。 |
| 关节与运动 | 选择父子件，设置类型/轴/原点/范围，预览运动，检查碰撞，导出可动资产 | 关节标注工具与统一 viewer 有直接交互基础，另有 URDF 管线和参数化关节库。先接人工配置与预览；自动推断、闭环机构和实体配合分别验收。 |
| 外观与材质 | 切换显示方式，选择材质，改颜色/粗糙度/金属度/透明相关参数，对照前后效果，保留贴图导出 | `cg_patch.py` 已有可记录操作的 GLB 材质修改器；统一 viewer 可复用显示层。贴图重烤有历史实验，UV 编辑、纹理绘制、自动美化不能视作现成通用能力。 |
| 生成与局部补全 | 调用自己的或官方 API 生成模型/部件，预览候选，选取结果并继续编辑 | 原产品文档已列方向；生成服务散布于相关项目，尚未形成插件提供商适配层。本次没有核验每家 API 的当前可用性。需补任务状态、取消、失败恢复和消费说明。 |
| 打印准备 | 尺寸、朝向、排盘、工艺、试切、3MF、交付切片器 | 当前 Print Prep v0.5 的完整模块，保留并接到工作台资产上。打印六步流程只属于此模块。 |
| 骨架与高级编辑 | 蒙皮、姿态、动画、生成式局部编辑、CAD 约束辅助 | 纳入探索区。动物 rig、骨架与 CAD 绑定实验各有边界，不作为首版“一键任意模型成功”的功能承诺。 |

“都应该有”落实为统一入口、持续接入清单与明确状态，而不是给每份历史脚本直接增加按钮。对用户有价值的是可组合的操作与可用产物。

## 4. 右侧工作区建议

用户打开工作台，首先看到当前模型。工具可以按任务随时切换，不要求先完成打印阶段。

```text
顶部：项目/模型 · 导入 · 撤销/重做 · 保存 · 导出
模块：编辑 | 拆件 | 修复 | 装配 | 运动 | 外观 | 打印

模型树/选区       持续显示的 3D 视口       当前工具参数
可折叠           直接点选与变换          预览 → 应用

底部：任务状态 · 操作历史 · 人/AI 修改 · 警告与恢复
```

- 在窄侧栏中折叠模型树，工具参数放抽屉或视口下方；避免所有模块平铺挤占视口。
- 切换工具保留相机与当前选择。炸件和运动预览属于查看状态；应用真实变换才改变资产。
- “打印”内部沿用现有六步流程。打印摆盘不能无意覆盖装配坐标或运动零位。
- 生成/SEG 的长任务进入任务区域，展示进度；等待期间仍能查看和执行不冲突的操作。
- 未实现的能力先保留在规划中；实际界面只展示可用入口和明确标注、可运行的实验入口。

## 5. 人和 AI 共用操作的实施原则

以下是待细化的设计约束，尚未定义新 Schema 或移动代码。

1. 按操作暴露工具，例如选件、变换、切割、改材质、设置关节。批量流程组合这些操作，人工按钮执行同一实现。
2. 明确输入资产版本、对象身份、坐标系、单位和选区。AI 基于旧版本提交修改时显式处理冲突，避免覆盖人的新操作。
3. 源文件保留，编辑形成可恢复版本；预览网格与编辑/导出网格分开。保存工程与导出下游格式各自验证。
4. 切割或重网格后更新对象、面标签、材质和关节引用；不能让失效标签/轴心静默继续使用。
5. 结果带操作摘要、警告和可检查产物。命令退出成功、几何有效、用户任务达成是不同层次。
6. 长任务有取消和失败状态。付费调用说明服务与消费，失败保留当前可用工程。
7. 面向开源分发提取独立工具包并记录来源/依赖；MDE 继续保存实验与证据，避免复制整仓或依赖开发者私有目录。

## 6. 建议接入批次与验收

### 第一批：通用工作区与可独立完成的编辑任务

将项目入口改为通用工作台，保留 Print Prep 模块；补模型树、多选、命名、隐藏/隔离、精确变换与尺寸、保存/恢复，以及 GLB/STL 导出。选择一个确定性拆件操作作为首个新工具：平面预览 → 切成两件 → 分别变换/导出，暂不把自动布置销孔绑定为必经步骤。

验收至少覆盖带材质的多对象 GLB、有效闭合 STL 和一份不满足切割前提的输入。人和 AI 交替操作同一模型；撤销/重开后状态一致；导出重新导入核对几何、变换、单位与应保留的材质。无 API 也可完成该任务；不支持的输入显示原因并保留原件。

这批会涉及通用资产状态和打印状态的关系，需要先确认实施方案；本次仅形成规划，没有修改运行时或迁移现有 job。

### 第二批：拆件修正、几何诊断与修复

加入连通块拆分、归组/合并、面区选择、开边/非流形诊断和有明确适用条件的封口。再接 SEG 候选与人工修正，保留纯手动路径。用独立于开发样例的模型验证；同时核对表面归属、源面保真与输出实体，不能仅检查水密。

### 第三批：装配、运动与外观

分别交付连接件/装配操作、人工关节配置与运动预览、材质参数编辑。各自有可独立完成的任务，不互相等待；自动推断和组合流水线在基础操作稳定后追加。有限碰撞采样不能表述成完整运动安全或实物配合保证。

### 后续：服务适配与高级能力

按需求频率和已验证能力接入生成/BYOK、骨架/蒙皮、局部生成式编辑、批量任务及其他宿主。优先比较成功任务的人工修正时间、总时长、Agent 消耗、重试与导出可用性，再决定专用模型投入。

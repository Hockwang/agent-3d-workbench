Exact Python dependencies are pinned in `uv.lock`; the frontend is pinned in `package-lock.json`. Pre-existing dependencies such as NumPy, SciPy, and MCP continue to use the license bundled with each package.

2026-09-23: preview and offline delivery added Three.js r185's DRACOLoader/KTX2Loader, Meshoptimizer, Draco/Basis WASM, and ktx-parse/zstddec. Full licenses and build notes are in `studio/web/vendor/CODECS-NOTICES.txt` and the LICENSE files in the same directory; the npm lockfile version is unchanged and the decoder has no CDN dependency. Aholo-Lux3D is used only as an interface and capability reference — its business logic was not copied; the contract is pinned to `71779ccd8290e999d980621439c728524830f422`.

Three.js's GLTFLoader, TransformControls, BufferGeometryUtils, and SkeletonUtils are taken directly from npm `three@0.185.0/examples/jsm/`, matching the existing r185 core.
The official add-on source was not modified; the distributed copies live in `studio/web/vendor/addons/`, with the MIT notice kept in `studio/web/vendor/THREE-LICENSE.txt`.
Installation uses the already-bundled HTML and vendored modules — static editing does not require Node.js; motion-editing verification/export adds a dependency on a local Node.js 20+ (the worker is already bundled, no `npm install` needed). Python dependencies are installed from the lockfile, and each wheel carries its own license.

References: [Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html), [Manifold](https://manifoldcad.org/docs/html/classmanifold_1_1_manifold.html), [Trimesh](https://trimesh.org/).

This round did not bring in research model forks or any third-party private source code from the author's research repo; the part-splitting and workflow experiments in the author's research repo are used only to identify operating boundaries and acceptance conditions.
This project's own code is released under the MIT license in `LICENSE`. Dependencies retain their respective licenses and notices.

## 2026-09-22 additions

- CadQuery 2.8.0 (Apache-2.0) and its OCP/OpenCascade kernel: precise solids, STEP/STL.
- Shapely 2.1.2 (BSD-3-Clause): 2D cross-section geometry; see `uv.lock` for the exact version.
- Blender 5.1.2 (external install, GPL): invoked via a background process calling its public bpy operations; the Blender binary itself is not placed in the source repo.
- Author's research repo / own mechanical_joints: a small standalone kernel copied in, with provenance and SHA256 in `studio/core/kernels/SOURCES.json`; other repos are not implicitly imported.
- The offline web page reuses the existing Three.js / GLTFLoader / OrbitControls; build artifacts are generated by scripts/build_delivery.mjs.
- Meshy/Tripo are public-API adapters for bring-your-own accounts; no private code, credentials, or dedicated service from any third-party product was reused.

## Model observation

yourdfpy 0.0.60 (MIT) is used for URDF parsing, the link graph, and forward kinematics; the dependency is distributed via the lockfile, and no private implementation from any third-party product was copied. Upstream docs: https://yourdfpy.readthedocs.io/en/latest/api/yourdfpy.html . The adapter layer disables automatic mesh processing so the observation tool doesn't implicitly weld/repair the geometry under test; the actual model and mesh-file fingerprints are preserved.

## Unified workbench UI

- [Pico CSS](https://github.com/picocss/pico) 2.1.1, MIT: reuses native HTML form, select, details, and focus styles. Placed in a low-priority CSS layer; the workbench's unified skin owns density, color, and the model-viewport layout.
- [Lucide](https://github.com/lucide-icons/lucide) / lucide-static 1.47.0, ISC (the package also keeps its own derived-icon notice): only the 15 SVGs actually bundled are used; no icon runtime is introduced.
- IBM Plex Sans (@fontsource/ibm-plex-sans 5.3.0), SIL OFL 1.1: locally bundles the Latin WOFF2 for the 400/500/600 weights; Chinese text uses the system's existing Chinese font.

Build entry point: `scripts/build_ui_assets.mjs`; the distributed assets and full licenses are in `studio/web/vendor/ui/`. The MCP App embeds fonts as data URIs and icons as static SVGs; there is no font CDN, no external icon requests, and no added continuous JavaScript animation.

## 2026-09-23 motion editing

- jsep 1.4.0 (MIT): formula AST parsing. Studio only interprets numbers, parameters, and a whitelisted set of math operations — it never runs user JS. Notice in `studio/web/vendor/JSEP-LICENSE`.
- JSZip 3.10.2 (MIT license selected): MotionForge ZIP export. Notice in `studio/web/vendor/JSZIP-LICENSE`.
- MotionForge's `KeyframeManager` and `ResultPackageExporter`: MotionForge is the plugin author's own project, public at https://github.com/Hockwang/MotionForge (the files in this repo correspond to commit `18a11fe`), released together with this repo under the same license; see LICENSE. The pinned commit, the original files, the SHA after local modification, and the three patches are in `studio/web/vendor/motionforge/SOURCES.json`.
- The capability target is set by reference to commercial comparable products, used only as a read-only capability comparison — their private workflows, code, or prompts were not copied. Local rigging continues to use its own workflow plus external Blender.

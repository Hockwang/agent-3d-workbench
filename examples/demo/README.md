# Demo asset: five-part mug

`examples/head-shell/` is bound to a source STL the user provides — it is
not redistributed with the plugin. This directory is the redistributable
alternative: a small toy object generated entirely by `make_demo_parts.py`.
No third-party model data: every vertex is generated by this script, so the asset carries the repository's own license (there is no separate license for it).

## Build it

```
uv run python examples/demo/make_demo_parts.py --out examples/demo/out
```

Deterministic (no randomness, no timestamps): running it twice produces
byte-identical output. It prints a JSON summary and writes, under `<out>/`:

- `parts/body.stl`, `parts/handle.stl`, `parts/lid.stl`, `parts/knob.stl`,
  `parts/base.stl` — millimetres, Z up, each independently watertight
- `demo-parts.glb` — the same five parts in one file, one named node per
  part (`body`/`handle`/`lid`/`knob`/`base`)

## Load it

**Edit workspace:** import `demo-parts.glb` from the workbench UI, or point
the AI at it:

```
studio_edit {"action": "import", "expected_revision": <workbench.revision, 0 for a fresh workspace>, "params": {"files": ["<abs>/demo-parts.glb"]}}
```

**Print workspace:** load the STL parts directly:

```
studio_load {"files": [
  "<abs>/parts/body.stl", "<abs>/parts/handle.stl", "<abs>/parts/lid.stl",
  "<abs>/parts/knob.stl", "<abs>/parts/base.stl"
]}
```

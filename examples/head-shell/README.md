# 头壳参数示例

`pikachu-round-eyes.json` 是本次原圆眼 Pikachu 样稿的参数，绑定文件内的 `source_sha256`。源 STL 由使用者提供，不随插件分发。它只用于相同源文件的重现，不是其他模型的自动默认设置。

在工作台启用「角色头壳制作」，使用 `shell-kit` 模板，上传匹配的 STL，在高级参数 JSON 粘贴此文件内容。参数：60 cm 头围样稿、Ø6×3 mm 磁铁、原眼内部网孔、闭嘴通风。尺寸和眼点是暂定值，正前方视线仍被挡，未真人试戴。

更换模型时重新检查方向、连通部件、颜色和局部点位，重新绑定源 SHA；不得去掉 SHA 校验复用旧索引。
